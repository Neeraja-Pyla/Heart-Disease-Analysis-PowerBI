# ❤️ Heart Disease Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing heart disease data using Microsoft Power BI. It presents data through interactive visualizations and dashboards to make patterns and trends easier to understand.

## 🎯 Project Objectives

- Analyze heart disease-related data.
- Identify patterns and trends in the dataset.
- Present key insights through interactive visualizations.
- Make data easier to understand through dashboards.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning
